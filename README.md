# SIM · 축구 중계 속 영어

SIM(Searching in Matches)은 축구 중계에서 쓰이는 영어 표현을 사전으로 찾고, 유튜브 중계 영상 속에서 실제로 나온 표현을 시간 순서로 모아 보는 웹 앱입니다.

## 화면

- **홈 / 사전**: 용어, 한글 뜻, 해설 예문으로 검색합니다.
- **중계 분석**: 유튜브 주소를 넣고 **표현 찾기**를 누르면, 그 영상의 자막 또는 음성을 읽어 표현을 시간축으로 나열합니다. 영상마다 탭이 따로 생깁니다.
- **저장**: 북마크한 용어를 다시 봅니다.
- **설정**: 다크 모드와 라이트 모드를 이 기기에 저장합니다.

표현을 누르면 그 시각으로 이동합니다. 다른 사이트 재생이 막힌 영상은 유튜브에서 열 수 있고, 표현 찾기는 그대로 동작합니다.

## 실행

Windows에서 PowerShell이 필요합니다. Node.js는 쓰지 않습니다.

1. `sim(개발 시작)\start-sim.bat`을 실행합니다.
2. 브라우저에서 [http://localhost:8787/](http://localhost:8787/)를 엽니다.

포트는 8787입니다. 이미 실행 중이면 같은 주소로 들어가면 됩니다.

## 중계 분석용 키

표현 찾기는 서버에서만 API를 호출합니다. 키는 브라우저로 나가지 않습니다.

`practice1022\.env` 파일을 만들고 아래 이름으로 값을 넣습니다. 이 파일은 Git에 올라가지 않습니다.

```
gemini_api_key=
supadata_api_key=
groq_api_key=
```

- 자막과 음성 추출: Supadata
- 용어 추출과 한글 설명: Google Gemini, Groq

키가 없어도 사전, 저장, 화면 설정은 사용할 수 있습니다.

## 폴더

| 경로 | 내용 |
